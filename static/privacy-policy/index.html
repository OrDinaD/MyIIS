Политика конфиденциальности

Дата вступления в силу: 12 июня 2026 года.

1. Общие положения

MyIIS — неофициальный клиент для доступа к сервисам IIS БГУИР. Приложение обрабатывает данные только для работы функций, которые пользователь запускает внутри приложения.

2. Какие данные обрабатываются

  • Логин и пароль, которые пользователь вводит для входа в личный кабинет.
  • Учебные данные, возвращаемые сервисами IIS: профиль, расписание, пропуски, отметки, рейтинг и связанные учебные сведения.
  • Настройки приложения, выбранный язык, состояние уведомлений и кэш данных, нужный для повторного открытия экранов.
  • Технические данные, необходимые для диагностики ошибок на устройстве пользователя.

3. Цели обработки

  • Авторизация пользователя и показ данных личного кабинета.
  • Работа расписания, ведомостей, пропусков, рейтинга, уведомлений и других функций приложения.
  • Диагностика, исправление ошибок и улучшение стабильности.

4. Хранение и передача

Данные авторизации сохраняются в системном хранилище iOS Keychain, если пользователь входит в аккаунт. Учебные данные могут кэшироваться локально на устройстве. MyIIS не продаёт персональные данные и не передаёт их рекламным сетям. Для получения данных приложение обращается к официальным сервисам IIS БГУИР.

5. Покупки и поддержка автора

Добровольная поддержка автора, если она доступна в приложении, обрабатывается через In-App Purchase и App Store. MyIIS не получает и не хранит данные банковских карт.

6. Выбор пользователя

Пользователь может выйти из аккаунта, очистить сохранённые данные приложения средствами iOS или удалить приложение с устройства.

7. Контакты

По вопросам конфиденциальности: @lokhotonkot.

Privacy Policy

Effective date: June 12, 2026.

1. General

MyIIS is an unofficial client for accessing BSUIR IIS services. The app processes data only to provide features that the user opens or enables in the app.

2. Data We Process

  • Username and password entered by the user to sign in.
  • Academic data returned by IIS services, including profile, schedule, attendance, grades, rating, and related study information.
  • App settings, selected language, notification state, and cached data required to reopen screens.
  • Technical data required to diagnose errors on the user's device.

3. Purpose

  • Authenticate the user and display student account data.
  • Provide schedule, gradebook, attendance, rating, notifications, and other app features.
  • Diagnose issues, fix bugs, and improve stability.

4. Storage and Sharing

Credentials are stored in the iOS Keychain when the user signs in. Academic data may be cached locally on the device. MyIIS does not sell personal data and does not share it with advertising networks. To retrieve account data, the app communicates with official BSUIR IIS services.

5. Purchases and Author Support

Voluntary author support, if available in the app, is processed through In-App Purchase and the App Store. MyIIS does not receive or store payment card data.

6. User Choices

The user can sign out, clear saved app data using iOS controls, or delete the app from the device.

7. Contact

For privacy requests: @lokhotonkot.
